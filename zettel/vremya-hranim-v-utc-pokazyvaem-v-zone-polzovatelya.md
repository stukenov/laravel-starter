# Время храним в UTC, а зону выбирает пользователь

Все временные колонки — `timestamptz`, приложение работает в UTC. У пользователя есть поле `timezone` со значением по умолчанию `Asia/Almaty`.

Из этого следует жёсткое правило вёрстки: **сервер никогда не отдаёт готовую строку с датой**. Он отдаёт момент времени в ISO 8601, а клиент форматирует его сам через встроенный `Intl.DateTimeFormat`.

Побочная выгода — ноль зависимостей на фронте. Ни `moment`, ни `dayjs`, ни `date-fns` не нужны, и это совпадает с требованием ничего не тянуть извне. См. [[nichego-vneshnego-pri-otrisovke]].

Альтернатива «всё жёстко в Asia/Almaty» отвергнута: она проще ровно до первого пользователя из другой зоны, после чего переделывается вся выдача.
