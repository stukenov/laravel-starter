# Миграции

- Первичный ключ: `$table->uuid('id')->primary()` плюс
  `alter table ... set default uuidv7()`. Не `$table->id()`.
- Даты: `timestampTz()` и `timestampsTz()`, никогда не `timestamp()`.
- Почта: тип `citext` — уникальность без учёта регистра без кода.
- Расширения ставятся первой миграцией. `uuidv7()` расширения не требует,
  в PostgreSQL 18 это встроенная функция.
- Тип внешнего ключа обязан совпадать с типом ключа таблицы-цели.

Полные правила: `AGENTS.md` в корне.
