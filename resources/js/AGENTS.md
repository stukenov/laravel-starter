# Фронтенд

- Только светлая тема. `dark:` в свой код не добавляйте. В `components/ui/`
  они остались от апстрима shadcn и не срабатывают.
- Даты форматирует клиент через `lib/datetime.ts` (встроенный `Intl`).
  Библиотеки дат не подключаются.
- Переводы — через `lib/i18n.ts`. Новый текст сразу в три локали.
- «На главную» — это `/`, а не `home()`: локаль подставляет сервер.
- Компоненты берутся из `components/ui/`, свои кнопки не изобретаются.
- Ничего внешнего: любой чужой домен заблокирует CSP.

Полные правила: `AGENTS.md` в корне.
